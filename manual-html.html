Manual de HTML para principiantes

Desde los fundamentos hasta la creación de páginas web.

Introducción Estructura HTML Elementos Atributos Recursos

1. Introducción a HTML

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para estructurar el contenido de las páginas web.

Permite organizar textos, imágenes, enlaces, tablas, formularios y otros elementos que forman parte de un sitio web.

2. Estructura básica de un documento HTML

Todo documento HTML debe contar con una estructura básica que permita al navegador interpretar su contenido. 

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
</head>
<body>
    <h1>Hola, mundo</h1>
    <p>Mi primera página web.</p>
</body>
</html>

3. Elementos HTML

Los elementos HTML se construyen generalmente mediante etiquetas de apertura y cierre.

Ejemplos de elementos

  • <h1>: encabezado principal.
  • <p>: párrafo.
  • <a>: enlace.
  • <img>: imagen.
  • <ul>: lista desordenada.
  • <table>: tabla.
  • <form>: formulario.

4. Atributos HTML

Los atributos proporcionan información adicional sobre los elementos HTML.

Ejemplo

<a href="https://www.example.com">
    Visitar página
</a>

En este ejemplo, href es el atributo que indica la dirección del enlace.
