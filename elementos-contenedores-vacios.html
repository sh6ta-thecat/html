Elementos contenedores y vacíos

En esta página aprenderás a distinguir los elementos HTML que pueden contener contenido de aquellos que no lo admiten.

1. Elementos contenedores

Los elementos contenedores tienen una etiqueta de apertura y una etiqueta de cierre. Pueden incluir texto y otros elementos HTML, según las reglas de cada elemento.

Ejemplo de párrafo: <p>

Este es un párrafo. Su contenido se encuentra entre las etiquetas de apertura y cierre.

Ejemplo de encabezado: <h2>

Este es un encabezado de segundo nivel

Ejemplo de agrupación: <div>

Contenido dentro de un div

El elemento div permite agrupar contenido sin añadir un significado semántico específico.

Ejemplo de enlace: <a>

Visita Wikipedia para consultar información.

Los elementos vacíos no admiten contenido interno y no utilizan etiquetas de cierre en HTML.

3. Elementos interactivos nativos

Detalles desplegables: <details> y <summary>

¿Qué es un elemento contenedor?

Es un elemento que puede incluir contenido interno, como texto u otros elementos permitidos por HTML.

¿Qué es un elemento vacío?

Es un elemento que no admite contenido interno y no utiliza una etiqueta de cierre en HTML.

Opciones sugeridas: <datalist>

Datalist proporciona sugerencias para el campo de entrada. El usuario también puede escribir otro valor.

Medida: <meter>

Ejemplo de nivel de batería:

Progreso: <progress>

5. Formateo de texto y legibilidad

Texto resaltado: <mark>

HTML permite resaltar información importante dentro de un texto.

Punto de salto: <wbr>

Esta es una palabra o dirección muy larga: https://ejemplo.com/documentacion/desarrollo/html

Wbr indica un lugar donde el navegador puede dividir una palabra o secuencia si necesita ajustar el texto.

6. Organización de opciones

Grupos de opciones: <optgroup>

7. Información de contacto

Elemento <address>

Contacto del responsable de esta página:
Correo: contacto@ejemplo.com

Address se utiliza para representar información de contacto relacionada con el documento o con el artículo que lo contiene.

8. Resumen

Elementos contenedores

  • <p>: párrafo.
  • <div>: agrupación genérica.
  • <a>: enlace.
  • <details>: sección desplegable.
  • <summary>: título de details.
  • <datalist>: lista de sugerencias.
  • <meter>: medida dentro de un rango.
  • <progress>: progreso de una tarea.
  • <mark>: texto resaltado.
  • <optgroup>: grupo de opciones.
  • <address>: información de contacto.

Elementos vacíos

  • <br>: salto de línea.
  • <hr>: separación temática.
  • <img>: imagen.
  • <input>: campo de entrada.
  • <wbr>: posible punto de salto de línea.
