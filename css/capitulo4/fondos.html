Fondos CSS

background-color y background-image permiten crear fondos de color o imágenes.

Vista previa

Fondo de una tarjeta

En este ejemplo se utiliza un fondo degradado como alternativa sin archivo de imagen.

Código CSS

 .tarjeta {
  background-color: #e8f1ff;
  background-image: url("fondo.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
