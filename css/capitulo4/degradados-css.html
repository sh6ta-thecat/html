Degradados CSS

Los degradados crean transiciones de color sin necesitar una imagen.

Vista previa

De azul a violeta

Prueba diferentes direcciones y colores en linear-gradient().

Código CSS

 .caja {
  background: linear-gradient(120deg, #2563eb, #9333ea);
  color: white;
  padding: 2rem;
  border-radius: 1rem;
}
