Filtros CSS

filter aplica efectos visuales como blur(), grayscale(), contrast() y brightness().

Filtro de color

Este bloque simula una superficie colorida. Aplica el filtro al elemento completo.

Código CSS

 .imagen {
  filter: grayscale(35%) contrast(110%);
}
/* Para quitar el efecto: filter: none; */
