Desbordamiento con overflow

overflow controla qué sucede cuando el contenido supera las dimensiones disponibles.

Vista previa

Este texto es intencionalmente largo para demostrar cómo aparece el desplazamiento cuando el contenido supera la altura disponible. Sigue leyendo para observar el comportamiento de overflow auto en una caja de dimensiones limitadas.

Código CSS

 .caja {
  width: 260px;
  height: 100px;
  overflow: auto;
  border: 2px solid #2563eb;
}
