# Desde HTML hasta Bootstrap — Tomo II: CSS
## Archivos de las semanas 3, 4 y 5

Este paquete contiene ejemplos HTML/CSS y dos simuladores interactivos.

### Estructura
- `semana3/`: colores, unidades y tipografía.
- `semana4/`: fondos, degradados, bordes, sombras y filtros.
- `semana5/`: modelo de caja, dimensiones, márgenes y desbordamiento.
- `simuladores/semana4/`: laboratorio de fondos y efectos.
- `simuladores/semana5/`: laboratorio del modelo de caja.

### Enlaces de simuladores para GitHub Pages
Si el repositorio se publica como `https://sh6ta-thecat.github.io/html/`, los enlaces serán:
- Semana 4: https://sh6ta-thecat.github.io/html/simuladores/semana4/
- Semana 5: https://sh6ta-thecat.github.io/html/simuladores/semana5/

Estos enlaces siguen la estructura solicitada, pero solo funcionarán públicamente después de subir las carpetas al repositorio y habilitar GitHub Pages.

### Cómo probar localmente
Abre el archivo `index.html` de cada carpeta con el navegador. Para los simuladores, abre `simuladores/semana4/index.html` o `simuladores/semana5/index.html`.

Los proyectos utilizan HTML, CSS y JavaScript nativo, sin Bootstrap ni bibliotecas externas.
