Combinadores de CSS

Descendientes, hijos directos y hermanos

1. Descendientes: espacio

Este párrafo está dentro del contenedor.

Este párrafo también es descendiente, aunque esté más adentro.

Regla: .descendiente p { color: #1769aa; }

2. Hijos directos: >

Hijo directo: recibe fondo amarillo.

Nieto: no recibe ese fondo.

Regla: .padre-directo > p

3. Hermano adyacente: +

Encabezado

Primer párrafo: está inmediatamente después del encabezado.

Segundo párrafo: no es adyacente al encabezado.

Regla: h3 + p

4. Hermanos generales: ~

Encabezado

Un elemento intermedio.

Primer párrafo posterior.

Segundo párrafo posterior.

Regla: h3 ~ p
