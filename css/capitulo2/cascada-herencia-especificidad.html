Cascada, herencia y especificidad

Por qué una regla CSS prevalece sobre otra

Herencia

Encabezado dentro del contenedor

Este párrafo hereda la fuente del contenedor, pero su color lo determina una regla específica para p.

La propiedad font-family se hereda normalmente; border no se hereda.

Especificidad

¿Qué color tiene este texto?

El color final es morado porque p#mensaje tiene más especificidad que #mensaje, .texto y p.

Prueba: abre las herramientas del navegador (F12), inspecciona el párrafo y revisa las declaraciones CSS tachadas y activas.

Valores relacionados con herencia

Este párrafo utiliza color: inherit para tomar el color de su padre.

Este párrafo utiliza color: initial, el valor inicial de la propiedad.

Este párrafo utiliza color: unset; como color es una propiedad heredable, se comporta como inherit.
